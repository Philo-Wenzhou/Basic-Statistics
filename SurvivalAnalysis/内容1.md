

# R-生存分析教程与数学原理详解

## 生存分析简介

生存分析是一种统计方法，用于分析事件发生的时间分布，特别适用于研究从开始时间到感兴趣事件（如死亡、疾病复发、设备故障等）发生的时间间隔。

**应用场景：**
- 医学研究：患者存活时间、疾病复发时间分析
- 可靠性工程：设备故障时间分析
- 社会学研究：失业持续时间、婚姻持续时间分析
- 市场营销：客户流失时间分析

**特点：**
- 处理删失数据（censored data）
- 关注事件发生的时间分布
- 可以同时考虑多个影响因素

## 生存分析的数学基础

### 基本概念定义

在生存分析中，需要理解以下几个核心概念：

1. **生存时间（Survival Time）**：从起始事件到感兴趣事件发生的时间间隔，通常用符号 $T$ 表示。

2. **生存函数（Survival Function）**：表示个体在时间 $t$ 仍然存活的概率，记作 $S(t)$。
   
   $S(t) = P(T > t)$

3. **风险函数（Hazard Function）**：表示在时间 $t$ 已经存活的个体在接下来的极短时间内发生事件的概率，记作 $h(t)$。
   
   $h(t) = \lim_{\Delta t \to 0} \frac{P(t \leq T < t + \Delta t | T \geq t)}{\Delta t}$

4. **累积风险函数（Cumulative Hazard Function）**：风险函数从0到 $t$ 的积分，记作 $H(t)$。
   
   $H(t) = \int_0^t h(u) du$

5. **概率密度函数（Probability Density Function）**：事件发生在时间 $t$ 的概率密度，记作 $f(t)$。
   
   $f(t) = \frac{dF(t)}{dt}$
   
   其中 $F(t) = P(T \leq t)$ 是累积分布函数。


### 概念间的数学关系
这些概念之间存在以下重要的数学关系：

$S(t) = 1 - F(t)$

$h(t) = \frac{f(t)}{S(t)}$

$S(t) = \exp(-H(t))$


### 常用分布模型
生存分析中常用的概率分布模型包括：

1. **指数分布（Exponential Distribution）**：假设风险恒定
   
   $h(t) = \lambda$
   
   $S(t) = \exp(-\lambda t)$
   
   其中 $\lambda$ 是常数风险率。

2. **Weibull分布（Weibull Distribution）**：允许风险随时间增加或减少
   
   $h(t) = k \lambda (\lambda t)^{k-1}$
   
   $S(t) = \exp(-(\lambda t)^k)$
   
   其中 $\lambda > 0$ 是尺度参数，$k > 0$ 是形状参数。当 $k = 1$ 时，Weibull分布退化为指数分布。

3. **对数正态分布（Log-Normal Distribution）**：假设生存时间的对数服从正态分布，即 $\ln(T) \sim N(\mu, \sigma^2)$，其中 $\mu$ 是均值参数，$\sigma^2$ 是方差参数。

4. **对数logistic分布（Log-Logistic Distribution）**：风险函数先增加后减少，其生存函数为 $S(t) = \frac{1}{1 + (\lambda t)^k}$，风险函数为 $h(t) = \frac{k \lambda (\lambda t)^{k-1}}{1 + (\lambda t)^k}$，其中 $\lambda > 0$ 是尺度参数，$k > 0$ 是形状参数。

让通过R代码来直观地理解这些分布：

```{r distribution_functions}
# 生存分析常用分布（指数分布、Weibull分布）生存函数可视化
# 1. 定义分布的核心函数（风险函数h、生存函数S）
# 指数分布：风险恒定
h_exp <- function(t, lambda) lambda  # 指数分布风险函数（lambda为常数风险率）
S_exp <- function(t, lambda) exp(-lambda * t)  # 指数分布生存函数

# Weibull分布：风险随时间变化（k为形状参数，lambda为尺度参数）
h_weibull <- function(t, lambda, k) k * lambda * (lambda * t)^(k-1)  # Weibull风险函数
S_weibull <- function(t, lambda, k) exp(-(lambda * t)^k)  # Weibull生存函数

# 2. 设置绘图参数与数据
t <- seq(0, 5, length = 100)  # 生成时间序列：从0到5，共100个等间隔时间点（模拟时间维度）
lambda <- 1  # 设定尺度参数lambda=1（简化计算，不影响分布趋势）

# 3. 绘制双面板生存曲线（左：指数分布；右：不同形状参数的Weibull分布）
par(mfrow = c(1, 2))  # 设置绘图布局：1行2列（左右两个子图）
# 左图：指数分布生存曲线
plot(t, S_exp(t, lambda), type = "l",  # type="l"表示绘制折线图
     main = "指数分布生存函数",  # 子图标题
     xlab = "时间t",  # x轴标签（时间）
     ylab = "S(t)（生存概率）",  # y轴标签（生存函数值）
     ylim = c(0, 1))  # y轴范围（生存概率0~1）

# 右图：不同形状参数k的Weibull分布生存曲线
plot(t, S_weibull(t, lambda, k=0.5), type = "l", col = "blue",  # k=0.5，蓝色线
     main = "Weibull分布生存函数（不同k值）", 
     xlab = "时间t", 
     ylab = "S(t)（生存概率）", 
     ylim = c(0, 1))
lines(t, S_weibull(t, lambda, k=1), col = "red")  # k=1，红色线（等同于指数分布）
lines(t, S_weibull(t, lambda, k=2), col = "green")  # k=2，绿色线
# 添加图例：说明不同颜色对应的k值
legend("topright", legend = c("k=0.5", "k=1", "k=2"), 
       col = c("blue", "red", "green"), lty = 1)  # lty=1表示实线

```

## Kaplan-Meier生存曲线分析

Kaplan-Meier方法是生存分析中最常用的非参数方法，用于估计生存函数。该方法特别适用于处理含有删失数据的生存资料。

### Kaplan-Meier估计的数学原理

Kaplan-Meier估计的基本思想是利用条件概率的乘法规则来估计生存函数。对于一组按时间排序的事件时间点 $ t_1 < t_2 < ... < t_k $，其中 $ d_i $ 是在时间 $ t_i $ 发生的事件数，$ n_i $ 是在时间 $ t_i $ 开始时的风险人数（即在 $ t_i $ 时刻仍然存活的个体数），则生存函数的Kaplan-Meier估计为：

$$
\hat{S}(t) = \prod_{t_i \leq t} \left(1 - \frac{d_i}{n_i}\right)
$$

### 创建生存对象

在R中，首先需要创建一个生存对象（Survival Object），这是进行生存分析的基础：

```{r create_survival_object}
# 创建生存对象
surv_object <- Surv(time = lung$time, event = lung$status)
cat("生存对象的前6行：\n")
head(surv_object)
```
这里，`time`参数表示生存时间，`event`参数表示事件状态（通常1表示事件发生，0表示删失）。

在代码中通过 `Surv(time = lung$time, event = lung$status)` 创建的“生存对象”，是生存分析的核心数据载体——它整合了**生存时间**和**事件状态**两大关键信息，输出结果 `[1]  306   455  1010+  210   883  1022+` 中每个数值的含义如下：

生存对象的输出有一个关键标识：**数值后带“+”表示“删失数据”，无“+”表示“事件发生数据”**，具体定义基于 `lung` 数据集的参数：
- `time = lung$time`：生存时间，单位为“天”（数据集默认定义）；
- `event = lung$status`：事件状态（`lung` 数据集约定：1=发生结局事件（如患者死亡），0=删失（如患者失访、研究结束时未死亡））。


| 生存对象输出 | 实际含义（对应前6个肺癌患者数据） |
|--------------|-----------------------------------|
| 306          | 该患者**发生结局事件**（死亡），实际生存时间为306天 |
| 455          | 该患者**发生结局事件**（死亡），实际生存时间为455天 |
| 1010+        | 该患者为**删失数据**（未发生死亡）：最后一次随访时间为1010天，之后未再追踪到（如失访），无法确定实际生存时间（实际生存时间≥1010天） |
| 210          | 该患者**发生结局事件**（死亡），实际生存时间为210天 |
| 883          | 该患者**发生结局事件**（死亡），实际生存时间为883天 |
| 1022+        | 该患者为**删失数据**（未发生死亡）：最后一次随访时间为1022天，之后失访或研究结束，实际生存时间≥1022天 |

生存对象的核心作用是“标记删失数据”，这对后续分析（如Kaplan-Meier生存曲线）至关重要：
- 无“+”的事件数据：会参与“生存概率下降”的计算（如306天死亡，会让对应时间点的生存概率降低）；
- 带“+”的删失数据：仅表示“该时间点仍存活”，不会让生存概率下降，仅用于调整“风险人数”（如1010+的患者，在1010天前会被计入“风险人群”，1010天后不再计入）。

简单来说，生存对象通过“+号”清晰区分了“确定的生存时间”和“不确定的随访时间”，是生存分析处理删失数据的基础。

- `time=5`：第5天有1名患者死亡；
- `n.risk=228`：第5天前，共有228名患者存活且未删失（即初始风险人群规模接近228人）；
- `n.event=1`：第5天仅1人死亡；
- `survival=0.9956`：截至第5天，患者存活超过5天的概率为99.56%（计算逻辑：1 - 1/228 ≈ 0.9956）；
- 置信区间`[0.9871, 1.000]`：真实生存概率有95%可能在98.71%~100%之间，估计精度极高（因早期样本量大）。

2. 中期时间点（如`time=306`天）：生存概率降至50%左右（中位生存期）
- `time=306`：第306天有1名患者死亡；
- `n.risk=86`：第306天前，仅剩86名患者仍存活且未删失（近半数患者已死亡或删失）；
- `n.event=1`：第306天1人死亡；
- `survival=0.5070`：截至第306天，患者存活超过306天的概率为50.7%——这接近**中位生存期**（生存概率降至50%的时间，是评估预后的核心指标），说明肺癌患者的中位生存期约为300天左右；
- 置信区间`[0.4427, 0.581]`：较早期变宽，但仍在合理范围，估计精度可接受。

3. 晚期时间点（如`time=883`天）：样本量减少，生存概率低且精度下降
- `time=883`：第883天有1名患者死亡；
- `n.risk=4`：第883天前，仅4名患者仍存活且未删失（大部分患者已死亡）；
- `n.event=1`：第883天1人死亡；
- `survival=0.0503`：截至第883天，患者存活超过883天的概率仅为5.03%（即100人中仅约5人能存活超过883天）；
- 置信区间`[0.0207, 0.123]`：显著变宽（因样本量极少），估计精度下降，此时的生存概率仅作参考。

从完整表格数据可提炼出肺癌患者**整体生存特征**：
1. **生存概率持续下降**：从第5天的99.56%，逐步降至第883天的5.03%，符合“疾病进展导致存活概率随时间降低”的客观规律；
2. **风险人群逐步减少**：`n.risk`从初始的228人，逐步降至晚期的4人，减少的原因包括“死亡”（主要）和“删失”（如失访、研究结束）；
3. **早期死亡风险较低，中期下降加速**：前50天内生存概率下降缓慢（如第59天仍有93.42%），50~300天下降速度加快（300天左右降至50%），300天后下降速度放缓（因剩余患者已属于“预后较好的少数群体”）；
4. **估计精度随时间降低**：早期（如前100天）置信区间窄，生存概率估计精确；晚期（如500天后）置信区间宽，因样本量少，估计不确定性增加。

## Cox比例风险模型分析

Cox比例风险模型是生存分析中最常用的半参数回归模型，它允许同时考虑多个协变量对生存时间的影响。

## Cox比例风险模型分析
Cox比例风险模型是生存分析中最常用的半参数回归模型，它无需假设生存时间的具体分布，且能同时纳入多个协变量，分析其对生存时间的综合影响。


### Cox模型的数学原理
#### Cox比例风险模型的基本形式
Cox比例风险模型的核心是描述“协变量如何影响个体的瞬时风险”，其基本形式为：  

$ h(t, \mathbf{x}) = h_0(t) \exp(\mathbf{\beta}^T \mathbf{x}) $  

其中各参数的含义如下：
- $ h(t, \mathbf{x}) $：具有协变量组合$ \mathbf{x} $的个体，在时间$ t $时的风险函数（即该个体在$ t $时刻发生结局事件的瞬时概率）；
- $ h_0(t) $：基准风险函数，指所有协变量取值均为0时的风险函数，仅与时间$ t $相关，与协变量无关（模型“半参数”的体现，无需定义其具体形式）；
- $ \mathbf{\beta} $：回归系数向量（如$ \beta_1, \beta_2,...\beta_p $），每个元素对应一个协变量的系数，用于衡量该协变量对风险的影响方向和强度；
- $ \exp(\mathbf{\beta}^T \mathbf{x}) $：风险比（Hazard Ratio, HR），是模型的核心解释指标——若协变量为分类变量，HR反映不同类别间的风险倍数；若为连续变量，HR反映该变量每增加1个单位时风险的变化倍数。


#### 比例风险假设（Proportional Hazards Assumption）
比例风险假设是Cox模型的**核心前提**，若不满足该假设，模型结果会出现偏差。其核心含义为：**不同协变量组合的个体，其风险函数之比不随时间$ t $变化，始终保持恒定**。  

该假设可通过数学推导验证，具体过程如下：  
对于任意两个协变量组合$ \mathbf{x}_1 $和$ \mathbf{x}_2 $，其风险函数之比为：  

$ \frac{h(t, \mathbf{x}_1)}{h(t, \mathbf{x}_2)} = \frac{h_0(t) \exp(\mathbf{\beta}^T \mathbf{x}_1)}{h_0(t) \exp(\mathbf{\beta}^T \mathbf{x}_2)} = \exp(\mathbf{\beta}^T (\mathbf{x}_1 - \mathbf{x}_2)) $  

推导逻辑说明：
1. 分子与分母中的基准风险函数$ h_0(t) $相互抵消（因$ h_0(t) $仅与时间相关，与协变量无关）；
2. 根据指数运算性质$ \frac{\exp(a)}{\exp(b)} = \exp(a - b) $，将指数项合并为$ \exp(\mathbf{\beta}^T \mathbf{x}_1 - \mathbf{\beta}^T \mathbf{x}_2) $；
3. 最终结果$ \exp(\mathbf{\beta}^T (\mathbf{x}_1 - \mathbf{x}_2)) $仅与协变量差异（$ \mathbf{x}_1 - \mathbf{x}_2 $）和回归系数（$ \mathbf{\beta} $）相关，与时间$ t $无关，由此验证“风险比恒定”的假设。
### 基础Cox回归

在R中，使用`coxph()`函数拟合Cox比例风险模型：

```{r basic_cox_model}
# 创建基础Cox模型（仅包含性别变量）
cox1 <- coxph(Surv(time, status) ~ sex, data = lung)
cat("基础Cox回归模型摘要：\n")
summary(cox1)
```

- **回归系数（coef）**：表示协变量对风险的影响方向和大小
- **风险比（exp(coef)）**：表示协变量每增加一个单位，风险增加的倍数
- **p值**：表示协变量的统计显著性

- `95%置信区间（CI）`：若不包含1，进一步支持影响显著（与P值结论一致）。

## 高级生存分析技术

### 时间依变协变量

在某些情况下，协变量的值可能随时间变化，这时需要使用时间依变协变量模型：

在某些情况下，协变量的值可能随时间变化，这时需要使用时间依变协变量模型.
以下基于 veteran（肺癌老兵） 和 cancer（癌症随访） 两个 R 自带数据集，分别改造并实现时间依变协变量 Cox 模型和竞争风险模型，代码可直接运行，且贴合临床数据逻辑：

```{r time_dependent_covariates}
# 1. 加载必需包
library(survival)  # 自带生存分析工具，含veteran数据集
veteran  # 加载肺癌老兵数据
data(cancer, package="survival")

# 2. 数据预处理：添加id、排除缺失、计算中位生存时间
veteran_td <- veteran %>%
  mutate(
    id = 1:nrow(.),  # 手动添加患者ID（关键：标识同一患者的不同时间区间）
    status = as.integer(status)  # 确保事件状态为整数（1=死亡，0=删失）
  ) %>%
  na.omit()  # 排除缺失值

median_surv <- median(veteran_td$time)  # 计算中位生存时间（约120天）

# 3. 构造时间依变数据：拆分随访区间
veteran_td_split <- lapply(unique(veteran_td$id), function(pat_id) {
  # 提取单个患者数据
  pat <- veteran_td[veteran_td$id == pat_id, ]
  
  # 第一段区间：start=0，stop=min(中位时间, 患者实际生存时间)
  seg1 <- data.frame(
    id = pat$id,
    start = 0,
    stop = min(median_surv, pat$time),
    status = ifelse(pat$time <= median_surv, pat$status, 0),  # 事件若在第一段发生，标记为1
    trt = pat$trt,  # 治疗组（1=标准，2=试验）
    age = pat$age,  # 年龄（固定协变量，不随时间变）
    karno = pat$karno  # 第一段体力评分（原始值）
  )
  
  # 第二段区间：仅对随访超中位时间的患者，start=中位时间，stop=实际时间
  if (pat$time > median_surv) {
    seg2 <- data.frame(
      id = pat$id,
      start = median_surv,
      stop = pat$time,
      status = pat$status,  # 事件若在第二段发生，标记为1
      trt = pat$trt,
      age = pat$age,
      karno = pat$karno - 8  # 时间依变：第二段体力评分降低8分（模拟随时间下降）
    )
    return(rbind(seg1, seg2))  # 合并两段数据
  } else {
    return(seg1)  # 仅返回第一段
  }
}) %>% do.call(rbind, .)  # 合并所有患者的区间数据

# 4. 拟合时间依变协变量Cox模型
td_cox_model <- coxph(
  formula = Surv(start, stop, status) ~ trt + age + karno,  # karno为时间依变协变量
  data = veteran_td_split
)
```

### 竞争风险模型

在实际研究中，可能存在多种可能导致观察结束的事件（如患者可能死于其他疾病而不是研究关注的疾病），这时需要使用竞争风险模型：

```{r competing_risks}
library(
# 1. 加载数据并预处理（移除NA+协变量数值化）
data(cancer)
cancer_cr <- cancer %>%
  select(time, status, age, sex, ph.ecog) %>%
  # 第一步：先移除所有原始变量的缺失值（避免后续计算产生NA）
  drop_na() %>%
  # 2. 重新编码事件状态（确保覆盖所有情况）
  mutate(
    event = case_when(
      status == 1 ~ 0,                     # 原status=1：删失
      status == 2 & ph.ecog >= 1 ~ 1,      # 关注事件：肺癌死亡
      status == 2 & ph.ecog == 0 ~ 2,      # 竞争事件：其他死亡
      TRUE ~ 99                            # 捕获所有未覆盖的情况（后续过滤）
    ),
    sex = as.numeric(sex) - 1,             # 性别转为数值（0=Male，1=Female，避免因子）
    ph.ecog = as.numeric(ph.ecog)          # 体力评分转为数值（0/1/2/3，移除因子格式）
  ) %>%
  filter(event != 99) %>%                  # 排除异常事件编码
  drop_na()  # 确保无NA

# 3. 拟合竞争风险模型（协变量均为数值型且无NA）
cr_model <- crr(
  ftime = cancer_cr$time,
  fstatus = cancer_cr$event,
  cov1 = as.matrix(cancer_cr[, c("age", "sex", "ph.ecog")]),  # 显式转换为矩阵（避免因子问题）
  failcode = 1
)

# 查看结果
summary(cr_model)
exp(cbind(SHR = coef(cr_model), confint(cr_model)))
```

#### 三、亚分布风险模型数学解析（选读，不必较真）
竞争风险模型的核心是**亚分布风险函数（Subdistribution Hazard Function**，其定义为：在“截至时间\( t \)未发生关注事件，且可能已发生竞争事件”的条件下，时间\( t \)发生关注事件的瞬时风险，公式如下：

1. 亚分布风险函数  
$$
h_{\text{sub}}(t|X) = \lim_{\Delta t \to 0^+} \frac{P(t \leq T < t+\Delta t, \Delta=1 \mid T \geq t \text{ 或 } \Delta=2)} {\Delta t}
$$  

- **$T$**：随访时间（从入组到事件发生/删失的时间）；  
- **$\Delta$**：事件类型（$\Delta=1$ 代表关注事件，如肺癌死亡；$\Delta=2$ 代表竞争事件，如其他疾病死亡；$\Delta=0$ 代表删失，如失访或研究结束未发生事件）；  
- **分母条件“$T \geq t$ 或 $\Delta=2$”**：核心区别于普通Cox模型——普通Cox仅将“$T \geq t$（截至$t$时刻未发生任何事件）”纳入风险集，而竞争风险模型需将“$T \geq t$（未发生事件）或 $\Delta=2$（已发生竞争事件）”均纳入风险集，以此修正竞争事件对关注事件风险的干扰。  


2. 比例亚分布风险假设（模型核心）  
竞争风险模型的核心假设是“协变量对亚分布风险的影响不随时间变化”，数学表达式为：  
$$
h_{\text{sub}}(t|X) = h_{\text{sub},0}(t) \cdot \exp\left(\beta_1 X_1 + \beta_2 X_2 + \beta_3 X_3\right)
$$  

- **$h_{\text{sub},0}(t)$**：基线亚分布风险函数，即所有协变量（$X_1, X_2, X_3$）均取0时，关注事件在时间$t$的基准风险；  
- **$\beta_1, \beta_2, \beta_3$**：协变量对应的回归系数（分别对应年龄$age$、性别$sex$、体力评分$ph.ecog$），反映协变量对“亚分布风险对数”的影响强度——系数为正表示协变量升高会增加风险，系数为负表示协变量升高会降低风险；  
- **$\exp(\beta)$**：亚分布风险比（Subdistribution Hazard Ratio, SHR），是竞争风险模型的核心解读指标，代表“协变量每增加1个单位时，关注事件亚分布风险的倍数变化”，具体含义如下：  
  - 若 $\exp(\beta) > 1$：协变量为**危险因素**，如本例中$ph.ecog$的$\exp(\beta)=3.784$，表示体力评分每升高1级（体力变差），肺癌死亡的亚分布风险升高2.784倍；  
  - 若 $\exp(\beta) < 1$：协变量为**保护因素**，如本例中$sex$的$\exp(\beta)=0.673$，表示性别从男性（编码0）变为女性（编码1）时，肺癌死亡的亚分布风险降低32.7%；  
  - 若 $\exp(\beta) \approx 1$：协变量对关注事件风险无显著影响，如本例中$age$的$\exp(\beta)=0.992$，表示年龄每增加1岁，肺癌死亡风险仅变化0.8%，且无统计学显著性。


#### 四、核心结论
1. **关键影响因素**：  
   - 体力状态（ph.ecog）是肺癌死亡的**最强危险因素**（体力越差，风险越高，SHR=3.784，\( p<0.001 \)）；  
   - 性别是显著保护因素（女性肺癌死亡风险比男性低32.7%，SHR=0.673，\( p=0.035 \)）；  
   - 年龄对肺癌死亡风险无显著影响（SHR=0.992，\( p=0.460 \)）。

2. **模型用途**：  
   该模型通过控制“其他死亡”的竞争干扰，得到的风险估计（SHR）比普通Cox模型更准确，可用于临床中肺癌患者的风险分层（如优先关注体力差的男性患者）。
